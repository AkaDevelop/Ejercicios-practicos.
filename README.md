## 📌 Descripción

Este repositorio contiene una colección de ejercicios prácticos desarrollados durante mi proceso de formación en programación y desarrollo de software.

Su propósito es aplicar los conocimientos adquiridos en clase, fortalecer el pensamiento lógico y mejorar progresivamente mis habilidades para resolver problemas mediante código.

Cada ejercicio representa una oportunidad para experimentar, aprender nuevas herramientas y construir bases sólidas como desarrollador.

## 🎯 Objetivos

- Fortalecer la lógica de programación y el pensamiento computacional.
- Aplicar conceptos teóricos mediante ejercicios prácticos.
- Desarrollar habilidades para analizar y resolver problemas.
- Mejorar la escritura, organización y legibilidad del código.
- Documentar el proceso de aprendizaje y evolución técnica.
- Construir una base sólida para futuros proyectos de software.

## 🛠️ Tecnologías y herramientas

Las tecnologías y herramientas utilizadas dependerán de los conceptos abordados en cada ejercicio.

- **Lenguajes de programación:** según cada actividad.
- **Visual Studio Code:** entorno de desarrollo.
- **Git:** control de versiones.
- **GitHub:** almacenamiento y seguimiento del código.

## 📚 Metodología de aprendizaje

El desarrollo de los ejercicios sigue un proceso de aprendizaje práctico:

1. **Análisis:** comprender el problema y sus requerimientos.
2. **Planificación:** identificar los pasos necesarios para resolverlo.
3. **Desarrollo:** implementar una solución mediante código.
4. **Pruebas:** verificar el funcionamiento y corregir errores.
5. **Mejora:** optimizar la solución y reforzar los conocimientos.

